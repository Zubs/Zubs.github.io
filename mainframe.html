Featured Build

JCLcheck

JCLcheck is a real, self-contained JCL validation engine — lexer, parser, AST, and rule-engine — that I built and shipped as a live SaaS-style product. It runs entirely without a mainframe: paste JCL into the browser workbench and it's validated against rules distilled from the IBM JCL Reference.

The engine checks statement ordering, DD-statement rules, keyword legality (with Levenshtein-distance "did you mean…" suggestions), DISP/SPACE/DCB/REGION/TIME/DSN value syntax, and full in-stream PROC resolution with symbolic parameter (&SYM) validation and DD-override matching, every diagnostic ships with a plain-English message and a suggested fix, built for people still learning the syntax.

The frontend is a Vue 3 workbench with a 3270-terminal-styled editor, line-numbered diagnostic gutter, and PF-key action bar (F1 Help / F5 Validate / F9 Sample / F12 Clear) — built for learning JCL and training new mainframe developers without needing z/OS access.
